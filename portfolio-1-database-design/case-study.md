# Case Study: NaijaPay

NaijaPay is a simulated Nigerian fintech that provides mobile wallets. Customers register with a verified phone number and email, open one or more wallets, and perform transactions: wallet funding, wallet to wallet transfers and merchant payments. Merchants belong to categories such as Groceries or Transport. The system must guarantee that balances are accurate, references are unique and every transaction can be traced to a wallet.

This same case study is used in all five portfolio activities.
